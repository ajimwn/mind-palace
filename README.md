# Mind Palace

> [!quote]
> "I am a brain, Watson. The rest of me is a mere appendix."
> — *The Adventure of the Mazarin Stone*

A personal cybersecurity knowledge base. Every technique studied, tool mastered, and case solved is filed here, organized by discipline.

## The Rooms

| Room | Identity | Discipline |
|---|---|---|
| [[Red]] | The Adversary | Offensive security |
| [[Blue]] | Scotland Yard | Defensive security and investigation |
| [[White]] | Mycroft's Office | Governance, risk, and compliance |
| [[Yellow]] | The Laboratory | Secure development |
| [[Green]] | The Irregulars | DevSecOps, cloud, and infrastructure |
| [[Casebook/Casebook]] | The Casebook | CTF, TryHackMe, and lab writeups |

## Layout

- Each color room holds **Notes** (*monographs*: concepts and reasoning) and **Tools** (*instruments*: cheat sheets and commands).
- The **Casebook** is divided by challenge category, and each case is filed using the [[Casefile]] template.

## The Method

1. **Observe**: gather every detail before forming a theory.
2. **Deduce**: reason from the evidence, not assumption.
3. **Verify**: test the conclusion in practice.
4. **Record**: file it here so it is never lost.
