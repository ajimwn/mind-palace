# Reverse Engineering: Reasoning Backward

> [!quote]
> "The grand thing is to be able to reason backward."
> — *A Study in Scarlet*

Start from the finished program and work back to the logic that produced it.

## Subjects

- Disassembly and decompilation
- Crackmes and license checks
- Anti-debugging and obfuscation
- Packers and unpacking
- Bytecode (Java, .NET, Python)

## First Moves

1. Identify the file type and architecture.
2. Run `strings`, `ltrace`, and `strace` for quick hints.
3. Open in a decompiler and locate the check logic.

## Instruments

Ghidra, IDA Free, radare2 or Cutter, GDB, jadx, dnSpy
