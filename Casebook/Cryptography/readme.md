# Cryptography: The Dancing Men

> [!quote]
> "What one man can invent, another can discover."
> — *The Adventure of the Dancing Men*

Ciphers, encryption schemes, hashes, and encodings. Break the code by understanding how it was made.

## Subjects

- Classical ciphers (Caesar, Vigenère, substitution)
- XOR and stream ciphers
- RSA and common attacks
- Symmetric encryption (AES modes, padding oracles)
- Hashing and cracking
- Encodings (Base64, hex, and variants)

## First Moves

1. Identify whether it is encoding, encryption, or hashing.
2. Look for patterns, repetition, and key length.
3. Try the standard attacks before anything exotic.

## Instruments

CyberChef, RsaCtfTool, hashcat, John the Ripper, Python (pycryptodome), dCode
