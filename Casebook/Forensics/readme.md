# Forensics: The Magnifying Glass

> [!quote]
> "You know my method. It is founded upon the observation of trifles."
> — *The Boscombe Valley Mystery*

Evidence is hidden in disk images, memory dumps, packet captures, and file metadata. Examine everything.

## Subjects

- Disk and filesystem analysis
- Memory forensics
- Network traffic (PCAP) analysis
- File carving and recovery
- Metadata and log analysis

## First Moves

1. Identify the file type (`file`, magic bytes).
2. Extract metadata and printable strings.
3. Check for embedded or appended data.

## Instruments

Autopsy, Volatility, Wireshark, binwalk, foremost, exiftool, strings
