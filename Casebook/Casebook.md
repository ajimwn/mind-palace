# Casebook

> [!quote]
> "When you have eliminated the impossible, whatever remains, however improbable, must be the truth."
> — *The Sign of the Four*

Every CTF challenge, TryHackMe room, and lab is a case. The Casebook is the permanent record of each investigation: what was found, how it was solved, and what was learned.

## Case Categories

| Category | Identity | Covers |
|---|---|---|
| [[Cryptography]] | The Dancing Men | Ciphers, encryption, hashing, encodings |
| [[Forensics]] | The Magnifying Glass | Disk, memory, network, and file analysis |
| [[Miscellaneous]] | The Curious Incident | Puzzles, scripting, jails, and oddities |
| [[OSINT]] | The Commonplace Book | Open-source intelligence and geolocation |
| [[Pwn]] | The Burglar | Binary exploitation |
| [[Reverse Engineering]] | Reasoning Backward | Disassembly, decompilation, crackmes |
| [[Steganography]] | The Blue Carbuncle | Data hidden in images, audio, and files |

## Filing a Case

1. Create a new note in the matching category folder.
2. Name it `Platform - Case Name` (e.g. `THM - Blue`, `picoCTF - Caesar`).
3. Insert the [[Casefile]] template.

## Ethics and Disclosure

- Publish only retired machines and concluded events.
- Never include flags or direct answers.
- Share methodology and lessons, not spoilers.
