# Steganography: The Blue Carbuncle

> [!quote]
> "The world is full of obvious things which nobody by any chance ever observes."
> — *The Hound of the Baskervilles*

A stolen jewel hidden inside a goose. Stego is data concealed in something that looks ordinary.

## Subjects

- Image steganography (LSB, metadata, channels)
- Audio steganography (spectrograms)
- Data appended to or embedded in files
- Text-based steganography
- Password-protected payloads

## First Moves

1. Check metadata and file structure for appended data.
2. Inspect individual color channels and bit planes.
3. View audio as a spectrogram.

## Instruments

steghide, zsteg, binwalk, exiftool, StegSolve, Audacity, Sonic Visualiser
